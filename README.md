# Karina Esquivel Portfolio

A modern, interactive portfolio showcasing my work in data analytics, dashboard development, automation, and software engineering.

**Live Website**
> https://karinaamores.github.io/Karina-Portfolio-Website/

---

## About

This portfolio was designed and built to demonstrate not only completed projects, but also the thought process behind solving real-world business problems.

Rather than simply displaying screenshots, each case study walks through:

- The Challenge
- My Approach
- The Solution
- The Impact

The goal is to give employers and collaborators a deeper understanding of how I analyze problems, design solutions, and deliver results.

## Featured Case Studies

### Bridge Condition Dashboard
**Missouri Department of Transportation**

Finalist – Innovation Challenge

Developed an interactive Power BI dashboard that transformed complex bridge condition data into an accessible decision-making tool for engineers and leadership.

**Highlights**
- Power BI
- Power Query
- DAX
- Dashboard Design
- Data Visualization

---

### AMP Dashboard
**Missouri Department of Transportation**

🏆 Director's Award Winner

Designed a statewide dashboard that consolidated transportation program reporting into an interactive executive dashboard.

**Highlights**

- Executive Reporting
- Power BI
- DAX
- Power Query
- User-Centered Dashboard Design

---

### TP-D Tracker

Created an internal tracking solution to organize transportation planning projects, improve visibility, and simplify project management workflows.

**Highlights**

- Power BI
- Workflow Automation
- Data Tracking
- Process Improvement

---

### ECNL Scheduling Engine

Designed and developed a Python scheduling engine to automate tournament scheduling while balancing numerous operational constraints.

This project later expanded to include an analytics dashboard for tournament management.

**Highlights**

- Python
- Scheduling Algorithms
- Automation
- Dashboard Analytics

---

### DRE & Phlebotomy Dashboards

Developed interactive public-facing dashboards supporting the Missouri Coalition for Roadway Safety to improve visibility into impaired driving initiatives.
